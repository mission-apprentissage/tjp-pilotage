Comment lire les pages consoles

  1. Tableau des données
  2. Barre de filtres géographiques
  3. Étiquettes de filtres actifs
  4. Volet de filtres sur les formations
  5. Champ de recherche textuelle
  6. Barre d’actions

  1. Tableau des données⚓

    Cette partie de l'écran contient les données relatives aux formations.

    Remarque - Rentrées scolaires précédentes⚓

    Par défaut, la rentrée scolaire la plus récente est affichée. Cliquer sur un chevron permet d'afficher les données des rentrées scolaires antérieures.

  2. Barre de filtres géographiques⚓

    La barre de filtres permet de modifier le contexte géographique des données de la table. Pour tous les filtres de la page, on peut sélectionner un choix dans le menu déroulant ou l’entrer au clavier.

    Cliquer sur Réinitialiser les filtres permet de remettre à zéro toute la sélection.

  3. Étiquettes de filtres actifs⚓

    Les étiquettes permettent de visualiser ou ajuster les dimensions sur lesquelles les données sont actuellement filtrées. Selon le périmètre ou les éventuelles analyses menées sur d’autres pages en début de visite, certains filtres seront peut être déjà actifs sur la page et visibles ici.

    Cliquer sur un X dans une étiquette permet de retirer la dimension correspondante.

    Remarque - Aucune étiquette⚓

    Lorsqu’il n’y a aucune étiquette, les données sont pour la France entière et toutes formations confondues.

  4. Volet de filtres sur les formations⚓

    Ce volet permet d’affiner un peu plus la liste des formations affichées à droite. Il est rétractable pour plus de confort de lecture en cliquant sur Masquer les filtres.

  5. Champ de recherche textuelle⚓

    Ce champ permet une recherche par mot-clé plutôt que via les filtres.

    Retourner à l'image

  6. Barre d’actions⚓

    Les principales actions possibles sur les données sont :

    • Exporter les données ;

    • Enregistrer la requête dans les requêtes favorites ;

    • Modifier l’affichage des colonnes.
